🚫⏪ What is the Negative Past Tense?

To form the negative past tense, first form the negative present (using m- or n-), then add the appropriate past tense ending to that negative form.

💡 Process: Negative Present → Add Past Tense Ending → Negative Past
📜 Main Rules for Negative Past
Step 1: Start with the negative present form
Step 2: Apply the same past tense changes:
  • Double the final letter if followed by an object/adverb
  • Add -iɛ / -eɛ (with possible linking vowel) if there is no object/adverb
Step 3: The negation marker (m- / n-) stays in place

📌 Key Notes on Negative Past
✓ Start with the negative present form.

✓ Then apply the same past tense changes you learned earlier:
  • Double the final letter if followed by an object/adverb
  • Add -iɛ / -eɛ (with possible linking vowel) if there is no object/adverb

✓ The negation marker (m-/n-) stays in place.

✓ For serialized verbs, negate and apply past tense mainly to the second verb.
